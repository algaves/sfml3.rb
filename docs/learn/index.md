# Learn sfml3-rb

Welcome to the guided learning path for `sfml3-rb`. These step-by-step tutorials will take you from setting up your first rendering pipeline to handling input and managing audio.

{: .note }
> Before starting, make sure you have [installed `sfml3-rb`]({% link installation/index.md %}).

## Tutorial index

1. **[Basic Game Loop]({% link learn/basic-game-loop.md %})** — Managing delta time, frame rates, and the window lifecycle.
2. **[Handling Input]({% link learn/handling-input.md %})** — Keyboard, mouse, touch, joystick and sensors.
3. **[Playing Audio]({% link learn/playing-audio.md %})** — Sound effects and music streaming, plus device enumeration.
4. **[Custom Rendering]({% link learn/custom-rendering.md %})** — Views, cameras, and applying custom GLSL shaders with RenderTexture.
