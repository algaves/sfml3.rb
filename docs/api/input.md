# Input API

Keyboard, mouse, joystick, touch, sensors, clipboard, and window events.

## Key classes/modules

| Class/Module | Purpose |
|---|---|
| `SF::Window::Keyboard` | Keyboard state queries |
| `SF::Window::Mouse` | Mouse position and buttons |
| `SF::Window::Joystick` | Joystick/gamepad state |
| `SF::Window::Touch` | Multi-touch input |
| `SF::Window::Sensor` | Motion sensors |
| `SF::Window::Clipboard` | System clipboard |
| `SF::Window::Event` | Event types and data |
| `SF::Window::WindowBase` / `SF::Window::Window` | Window and event handling |

See `sig/window/` and `ext/window/` for details.
