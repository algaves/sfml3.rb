# API Reference

Generated API references covering the major subsystems of `sfml3-rb`. These pages summarize the public API surface reflected in the RBS signatures and C extension docs.

## Subsystems

1. **[Graphics]({% link api/graphics.md %})** — `RenderWindow`, `Sprite`, `Texture`, `Font`, `Text`, `View`, shapes, transforms, shaders, and RenderTarget.
2. **[Audio]({% link api/audio.md %})** — `Sound`, `Music`, `SoundBuffer`, `SoundRecorder`, `SoundStream`, and Listener.
3. **[Input]({% link api/input.md %})** — `Keyboard`, `Mouse`, `Touch`, `Joystick`, `Sensor`, Clipboard, and window events.
4. **[System]({% link api/system.md %})** — `Clock`, `Time`, `Sleep`, `Vector2`, `Vector3`, `Rect`, and utility types.
5. **[Network]({% link api/network.md %})** — `Ftp`, `Http`, `TcpSocket`, `UdpSocket`, `TcpListener`, `IpAddress`, and `Packet`.
