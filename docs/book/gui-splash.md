# Recipe: Logo & Splash

A splash screen is a timed animation: show a logo, animate it in, wait, move on. It is the simplest thing a `Clock`, a `Sprite` and a colour are for, and it gives a small game an introduction instead of starting cold. This recipe animates a logo in, then drops into the menu from [Menus & HUD]({% link book/gui-menus.md %}).

> **Advanced**

## Goal

A 900×620 window that opens on a splash screen: a logo pops in and fades up, a title follows, and a pulsing prompt appears. Enter or a click continues to a small menu; `r` replays the splash; escape quits.

## How the code works

### 1. Load the logo texture and place it

`Texture.from_file` must be created after the window, because the GL context lives there; wrapping it in a `Sprite` and setting `origin` to half the texture size lets the logo be positioned by its centre.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 34-38 %}

### 2. Seed the timeline and the alpha helper

`state`, the `splash` `Clock` and `menu_selected` hold the animation and menu state, while `alpha_of` rebuilds an RGBA colour with a new alpha so the fade maths stays readable.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 40-46 %}

### 3. Poll events to skip and replay

`poll_events!` lets a click, Enter or space leave the splash for the menu, `r` returns to the splash and restarts the clock, Up/Down move the menu cursor, and escape quits.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 49-64 %}

### 4. Drive the pop-in from the clock

Inside the splash branch, `splash.elapsed_time` is the timeline: an ease-out scale grows fast then settles, and the sprite's alpha ramps to full so the logo fades in as it pops.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 68-75 %}

### 5. Bring the title in late

Once `t` passes half a second the title appears, its alpha computed from the time since that point so it fades in rather than snapping on.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 77-81 %}

### 6. Pulse the prompt

After a further delay the prompt's alpha follows a `sin` of the clock, breathing to signal "press a key" without any keyframes to store.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 83-88 %}

### 7. Draw the small menu

When `state` is `:menu` the same loop draws a title and two buttons built from `Rect` bounds, highlighting `menu_selected`, then `window.display!` presents the frame.

{% example ruby examples/subsystems/gui_splash/gui_splash.rb 89-102 %}

## Ingredients

| Class | Subsystem | Role | Key methods |
| --- | --- | --- | --- |
| `Texture` / `Sprite` | Graphics | The logo splash | `Texture.from_file`, `Sprite.new`, `origin=`, `scale=`, `color=` |
| `Clock` | System | The splash timeline | `new`, `elapsed_time`, `restart!` |
| `Text` / `Font` | Graphics | Title and prompt | `Text.new`, `position=`, `fill_color=` |
| `RectangleShape` | Graphics | The small menu buttons | `new`, `position=`, `fill_color=` |
| `Mouse` / `Event` | Window | Skip and menu selection | `position`, `mouse_button`, `code` |

See the [Graphics API]({% link api/graphics.md %}) for `Sprite`, and the [System API]({% link api/system.md %}) for `Clock`.

The complete program, ready to copy into `examples/subsystems/gui_splash/gui_splash.rb` and run.

{: .note }
> The logo is generated by [`script/generate_example_logo.rb`](https://github.com/algaves/sfml3.rb/blob/main/script/generate_example_logo.rb) with pure Ruby, so there is no image-editor dependency. Because the timeline is a function of the clock, replaying or lengthening the splash is a one-line change.
