# Part I — Essential

The irreducible core: the window, the event queue, and the three class families every drawable is built from. Master these and the rest of the Book is arrangement.

1. **[Hello Shapes]({% link book/hello-shapes.md %})** &middot; *Essential* — The five building blocks in one minimal loop.
2. **[Window]({% link book/window-classes.md %})** &middot; *Essential* — `WindowBase` vs `Window` vs `RenderWindow`.
3. **[Events]({% link book/event-wait.md %})** &middot; *Essential* — The event model: types, fields, and inspect (`poll_event!`) vs wait (`wait_event!`).
4. **[Transformable]({% link book/shape-transforms.md %})** &middot; *Essential* — Origins, bounds, hit-testing and composed `Transform`s.
5. **[Shape]({% link book/drawing-shapes.md %})** &middot; *Essential* — `CircleShape`, `RectangleShape`, `ConvexShape`: styling, tessellation and texturing.
6. **[Drawable]({% link book/custom-drawable.md %})** &middot; *Essential* — The `Drawable` contract on a plain Ruby object.
7. **[Text & Fonts]({% link book/text-basics.md %})** &middot; *Essential* — `Font` and `Text`: sizes, styles, spacing, alignment and measuring.
