# Part II — Basic

With the essentials in hand, these recipes add the input devices and the artwork pipeline that turn a demo into a game.

1. **[Bouncing Shapes]({% link book/bouncing-shapes.md %})** &middot; *Basic* — Collision, mouse-drag and spawning in an interactive app.
2. **[Keyboard]({% link book/keyboard.md %})** &middot; *Basic* — Real-time key state and scancode/keycode mapping.
3. **[Mouse]({% link book/mouse.md %})** &middot; *Basic* — Window-relative and desktop position, button state.
4. **[Image Pixels]({% link book/image-pixels.md %})** &middot; *Basic* — `Image` editing, blitting, colour-keying and save/reload.
5. **[Graphics Assets]({% link book/graphics-assets.md %})** &middot; *Basic* — Sprite sheets, `Texture.from_image`, pixel edits and `RenderTexture`.
6. **[Character Animation]({% link book/sprite-animation.md %})** &middot; *Basic* — A character with idle, walk and run clips over a runtime atlas.
