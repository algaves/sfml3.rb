# Part III — Intermediate

Gameplay systems built on the basics: the remaining input devices, collision, levels, audio analysis, and defining your own geometry.

1. **[Joystick]({% link book/joystick.md %})** &middot; *Intermediate* — Connected pads, axes, buttons and hot-plug.
2. **[Touch]({% link book/touch.md %})** &middot; *Intermediate* — Multi-touch fingers and touch events.
3. **[Sensor]({% link book/sensor.md %})** &middot; *Intermediate* — Accelerometer/gyroscope/… availability and values.
4. **[AABB Collisions]({% link book/aabb.md %})** &middot; *Intermediate* — Axis-aligned boxes, overlap resolution and simple physics.
5. **[Tilemaps]({% link book/tileset.md %})** &middot; *Intermediate* — Building levels and environments from a tileset, in two render modes.
6. **[Audio Visualizer]({% link book/audio-visualizer.md %})** &middot; *Intermediate* — Real-time bars from `SoundBuffer#samples`.
7. **[Custom Shape]({% link book/custom-shape.md %})** &middot; *Intermediate* — A `Shape` subclass supplying its own geometry.
