# Examples

Runnable demos for `sfml3-rb`, grouped by what they demonstrate. Examples need a real display; headless machines can run them under `xvfb-run -a` with `SFML_EXAMPLE_FRAMES=120`.

## Example index

1. **[2D Bouncing Ball]({% link examples/bouncing-ball.md %})** — Simple physics, collision response against window edges.
2. **[Sprite Animation]({% link examples/sprite-animation.md %})** — Working with sprite sheets and `texture_rect`.
3. **[Audio Visualizer]({% link examples/audio-visualizer.md %})** — Basic real-time visualization using `SoundBuffer#samples`.
